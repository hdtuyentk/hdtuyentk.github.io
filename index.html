Before
SDK and monetization tasks for every game lived in one large Google Sheet, and the changelog was rewritten by hand for each release.
After
A web app that groups tasks per game and platform into releases, tracks publish dates and rollout, and produces the changelog from the same data.

Next.js, Prisma, Turso, Vercel. Internal tool, so there is no public link.
